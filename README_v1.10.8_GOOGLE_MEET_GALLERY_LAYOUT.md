# WebInternDev v1.10.8 — Google Meet-style adaptive gallery

## Changes
- Removed the permanent Screen Share placeholder from the meeting stage.
- When no screen is being shared, participant tiles expand to fill the full stage.
- When the Host starts screen sharing, the shared screen becomes the large focus area and participants move into a compact side gallery on desktop/tablet.
- On smaller screens, the shared screen stays full-width and participants appear below it in a responsive grid.
- When the Host stops sharing, the shared-screen tile is removed immediately and the participant gallery expands again.
- Existing pin, fullscreen, camera, microphone, chat, reactions, emotes, and LiveKit screen-share behavior are preserved.
