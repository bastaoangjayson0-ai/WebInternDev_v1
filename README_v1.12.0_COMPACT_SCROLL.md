# WebInternDev v1.12.0 — Compact Small Calls + Space-Based Scrolling

- 1–3 participants no longer get an artificial fixed-height participant scroll area.
- All 1–3 participant tiles remain visible and the meeting controls stay immediately below the gallery.
- 4+ participants use a bounded participant viewport sized from the available meeting space.
- The participant gallery scrolls vertically on desktop, tablet, and phone only when its content exceeds the available viewport.
- Full gallery uses responsive columns; screen-sharing participant rail remains independently scrollable for larger calls.
- Active-speaker priority is preserved: speaking participants still move to the front.
- Active emote priority is preserved after active speakers.
- No participant-ordering feature was removed.
