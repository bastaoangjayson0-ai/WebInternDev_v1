# WebInternDev v1.10.5 — All-Device Participant Touch Scroll

Applied to v1.10.4.

- Phone: 2-column participant grid with a dedicated native vertical scroll viewport.
- Tablet: 3-column participant grid with a dedicated native vertical scroll viewport.
- Desktop: dedicated participant sidebar with a vertical scrollbar.
- Main meeting area stays fixed while the participant gallery scrolls.
- Native touch scrolling enabled with touch-action: pan-y and -webkit-overflow-scrolling: touch.
- Horizontal participant scrolling disabled.
- Screen-sharing mode preserves participant scrolling.
