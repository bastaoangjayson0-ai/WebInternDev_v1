# WebInternDev v1.12.2 — Overflow-Gated Participant Scrolling

- Participant scrolling is disabled when all visible tiles fit in the available gallery space.
- Scrolling activates automatically when the gallery overflows.
- Mouse wheel/trackpad over participant tiles explicitly scrolls the participant viewport when overflow exists.
- Touch scrolling remains available on phones/tablets.
- When there is no overflow, wheel/touch can continue to scroll the normal page/control area.
- Active-speaker-to-front and emote priority are preserved.
