# WebInternDev v1.8.0 — Interactive Emote Selection

- Added an **Interactive Emote** selector to the meeting controls.
- The selected emote is used when the user holds their own participant tile.
- Included current emotes: SHEEESHHH and Slap.
- Added disabled **Add emote later** slots so more emotes can be inserted without redesigning the picker.
- The picker is responsive for desktop and mobile.
- Existing reaction, camera, screen-share, pin, chat, and participant behavior is preserved.
