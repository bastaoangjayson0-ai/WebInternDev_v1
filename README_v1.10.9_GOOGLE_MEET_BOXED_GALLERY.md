# WebInternDev v1.10.9 — Google Meet-style boxed participant gallery

- Screen sharing uses a large presentation box on the left and a compact 3-column participant box gallery on the right on desktop.
- When sharing stops, the shared-screen area disappears completely and participants expand into a full-width 3-column box gallery.
- Tablet and phone layouts use responsive 2-column boxes with vertical scrolling.
- Rounded participant cards, consistent spacing, and dark meeting surfaces are styled to resemble the Google Meet layout shown in the reference image.
- Existing password, admin join notice, chat read indicator, pin, camera, microphone, reactions, and emote features are preserved.
