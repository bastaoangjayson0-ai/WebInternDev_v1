# WebInternDev v1.5.5 — Screen Share Sources

Host screen sharing now uses LiveKit ScreenShareCaptureOptions to let the browser offer its native picker for an entire monitor, an individual window, or a browser tab. PDFs, PowerPoint, Excel, Word, websites, and other content can be shared by opening them in the selected window/tab. Browser support determines whether system/tab audio is available. No Supabase changes are required.
