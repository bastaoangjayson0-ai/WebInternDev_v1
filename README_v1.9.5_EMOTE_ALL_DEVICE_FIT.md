# WebInternDev v1.9.5 — Emote All-Device Fit

- Emote picker is viewport-anchored on phones and tablets so it cannot open off-screen.
- Picker width is constrained to the visible device viewport and can scroll vertically if needed.
- SHEEESHHH and FAAAAH are centered relative to the participant tile.
- Emote artwork is sized from the participant tile width to match the avatar footprint.
- Effects remain centered around the artwork without pushing the layout.
- Desktop behavior remains unchanged except for the improved avatar-footprint sizing.
- Existing 5-second cooldown, sounds, reactions, dark theme, mobile/tablet layout, and synchronized pin behavior are preserved.
