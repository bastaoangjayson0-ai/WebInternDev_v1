# WebInternDev v1.13.3 — Overflow-gated participant scrolling

- Participant scrollbar is hidden/inactive when all tiles fit in the visible gallery.
- Scrollbar automatically activates when rendered participant tiles overflow.
- Mouse wheel scrolling works while the pointer is directly over any participant tile.
- Phone/tablet finger swipe scrolling uses native touch scrolling on the gallery.
- The gallery itself remains the only scroll surface when overflow exists.
- No participant ordering, screen-share, active-speaker, or tile behavior was intentionally changed.
