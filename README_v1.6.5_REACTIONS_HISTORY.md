# WebInternDev v1.6.5

## New features
- Animated meeting reactions for User, Host, and Admin.
- Reactions are broadcast through the LiveKit data channel and float over the shared-screen/stage for all participants.
- Admin Attendance panel now acts as call history management.
- Admin can delete an individual history entry or clear all call history.

## Deployment
Replace the project files in GitHub and commit. Vercel will redeploy automatically.
